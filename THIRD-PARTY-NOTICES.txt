THIRD-PARTY NOTICES
===================

File Browser's own code is licensed as stated in this repository. The Windows
installer (FileBrowser-<version>.msi) contains File Browser (filebrowser.exe and
its web app) and the open-source libraries compiled into it, listed below. On
installation it downloads those of the unmodified third-party programs below
that are not already installed on the machine into
%LOCALAPPDATA%\FileBrowser\tools and checks each against a pinned SHA-256 (see
tools-manifest.json). They are separate programs, each under its own license.

    The crates compiled into the program are listed with their licenses in
    licenses\rust-crates.txt, generated from Cargo's metadata when the installer

npm packages (mega.nz helper)
-----------------------------

The mega.nz helper (app\mega-sidecar) bundles the npm packages listed in
licenses\npm-packages.txt (name, version, license, repository), generated from
its node_modules when the installer is built. Their license files stay inside
each package folder under app\mega-sidecar\node_modules.
