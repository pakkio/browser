installer (FileBrowser-<version>.msi) contains only File Browser itself. On first
run it downloads the unmodified third-party programs below into

tools-manifest.json). They are separate programs, each under its own license.

npm packages (production dependencies)
--------------------------------------

The application bundles the npm packages listed in licenses\npm-packages.txt
(name, version, license, repository), generated from node_modules when the
installer is built. Their license files stay inside each package folder under
app\node_modules. The package "pause" has no license field in its package.json;
its Readme states the MIT License.
